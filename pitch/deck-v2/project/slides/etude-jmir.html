Note de qualité sur l’échelle MARS, utilisée pour évaluer les applications de santé. Une autre revue (Doria et coll., 2021) conclut qu’aucun essai n’a mesuré l’effet de ces applications sur l’accès aux soins après une agression. Boussole veut être la première évaluée, avec la Chaire de l’UQAM.
